## FAQ

### What is XCutors?

XCutors is a collection and launcher for multiple popular Windows-based Roblox executors, designed to let users manage and switch between tools like Volt, Synapse Z, Potassium, and Wave from a single interface.

### Which executors are included?

The package ships with support for Volt, Synapse Z, Potassium, Wave, and includes the universal xcutorsLoader for simplified attachment workflows.

### Is XCutors free to use?

XCutors itself is free and open-source. However, some included executors may require their own licenses or subscriptions from their respective developers.

### What Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Windows 7 and 8.1 may work but are not officially tested or guaranteed.

### Why is my anticomponent flagging the application?

Some anticomponent tools issue false positives for any software that interfaces with external processes. You can whitelist the XCutors folder in your security software settings.

### How do I update the executors?

XCutors has a built-in updater. Navigate to Settings > Updates and click 'Check for Updates' to download the latest versions of all bundled executors.

### Can I add custom executors to the loader?

Yes. Place compatible executor DLLs in the /executors/custom/ folder and restart XCutors. The loader will detect and list them on the dashboard.

### What scripts work with XCutors?

XCutors runs standard Lua and LuaU scripts. Most community scripts written for Fluxus, Synapse, or similar executors are compatible out of the box.

### Where can I report bugs or request features?

Open an issue on the GitHub repository Issues tab with a detailed description, steps to reproduce, and your system specifications.
